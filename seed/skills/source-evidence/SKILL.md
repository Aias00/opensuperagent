# Source evidence

1. Translate the question into specific factual claims and identify available primary sources.
2. Inspect local implementation and connected records before asking for context already available.
3. For changing or uncertain external facts, consult current authoritative documentation when the necessary tool is available.
4. Record supporting source paths/URLs and the exact scope of each claim. Respect access boundaries.
5. Mark inferences and disagreements explicitly. Never invent quotations, references or access to unavailable material.
6. Summarize the answer for the reader, including relevant limitations and unanswered questions.

Deliver: concise findings with supporting evidence and a clear distinction between observation and inference.
