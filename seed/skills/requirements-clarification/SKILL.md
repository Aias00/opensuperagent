# Requirements clarification

1. Restate the desired outcome in concrete terms using the existing conversation and artifacts.
2. Identify constraints and observable acceptance criteria; separate requirements from implementation choices.
3. Resolve routine details with reversible assumptions. Ask only for information that materially changes scope or blocks progress.
4. If clarification is essential, ask one concise question with context and a small set of useful choices.
5. Recommend the most appropriate available Worker for implementation or research and state why.

Deliver: a short implementation-ready brief, acceptance criteria and explicit remaining questions. Use needs_input only for a real unresolved dependency.
